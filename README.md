# 时素小说工作台

面向 DSH（DeepSeek Harness）桌面端的中文长篇小说创作工作台。

它把「时间轴」当作小说的骨架：**先确定事情发生的先后顺序，再决定这一章该让 AI 看到什么**。写第 30 章时，AI 拿到的是第 30 章这个节点上的世界状态——角色此刻是练气期，而不是全书末尾才到的金丹期。

> **状态：设计与开发中，尚无可用版本。**
> 当前仓库是插件骨架，`dsh-shisu` 还不能安装使用。

## 它要解决什么

常规 AI 写小说软件把「全书角色卡」塞给模型，三个问题同时存在：

- **卡精简了** → 信息不够，角色写得扁平
- **卡完整了** → 上下文被大量用不上的设定污染
- **最要命的是时态错位**：卡上写的是全书/后期状态，模型写开篇时已经知道角色日后会到金丹期，于是提前泄露、提前成长、提前用上还没得到的法宝

时素的做法：角色卡不是一份文件，而是**某个时间节点上的一次查询结果**。

## 核心设计

### 时间轴

不是甘特图，也不是严格年表。重点是**先后顺序**，不是具体时刻：

- 元素之间至少有三种关系：**先后 / 并列 / 差异**
- 知名网文在时间线上常有硬伤，读者也不在意——所以不追求绝对时间，只保证「谁在谁之前」
- 节点不等于章节：一章可以跨多个节点，一个节点也可以横跨多章

### 世界切片

按当前节点供给上下文，而不是按全书供给：

- 角色卡 = 基础卡 + 节点状态增量
- 供给的是「事实 + 可见性」，角色卡只是其中一种视图
- 未回收的伏笔、上一节点的摘要，随节点一起带出

### 工作区 ≠ 书

本插件是插件，不是 IDE：在哪个工作区工作，不影响书本身。

- 默认全局书库 `~/.dsh/shisu/books/`
- 单本书可以指向外部目录，书库只存路径索引
- 会话级 focus 记住「当前在写哪本」

## 适用范围

**只做中文长篇小说（网文）。** 其他语言、短篇、其他体裁既不设计也不测试，也不承诺效果；欢迎基于本项目自行魔改，但不提供支持。

## 安装

尚不可用。骨架完成后的目标形态：

```sh
dsh plugin --profile web add dsh-shisu
```
